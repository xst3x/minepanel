# Fabric Resolver

**Source**: `src/core/resolvers/fabric.ts`

Queries the **Fabric Meta API** (`meta.fabricmc.net`). It resolves the tripartite dependency matrix: Minecraft game version, Fabric Loader version, and Fabric Installer version, generating server launch jars.
