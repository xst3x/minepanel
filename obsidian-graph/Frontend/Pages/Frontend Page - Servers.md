# Frontend Page - Servers

Main server dashboard page presenting status cards, player counters, CPU/RAM meters, and quick actions for all servers.

## Key Components
- Server cards with real-time status indicators.
- Filter and search bar by name, tag, and game type.
- 'Create Server' action button opening server setup wizard.
