# Frontend File Manager View

**Source**: `src/frontend/src/pages/server/Files.tsx`

Comprehensive in-browser file explorer:
- Tree and list views of server directories.
- In-browser code editor with syntax highlighting for YAML, JSON, properties, and scripts.
- Drag-and-drop file upload dropzone.
- Single-click zip archiving and folder downloads.
