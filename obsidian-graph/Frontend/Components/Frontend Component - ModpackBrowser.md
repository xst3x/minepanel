# Frontend Component - ModpackBrowser

Modal dialog allowing users to browse, search, and select modpacks from Modrinth and CurseForge.

## Features
- Search by keyword and Minecraft version.
- Displays modpack summaries, icons, and download stats.
- Triggers background modpack installation via API.
