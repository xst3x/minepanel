# Frontend Component - ServerLayout

Contextual wrapper layout for individual server management pages.

## Features
- Server header with power controls (Start, Stop, Restart, Kill).
- Status badge (Running, Stopped, Starting).
- Sub-navigation tabs: Overview, Console, Files, Content, Automation, Backups, Players, Logs, FTP, Properties, API Keys, Settings.
