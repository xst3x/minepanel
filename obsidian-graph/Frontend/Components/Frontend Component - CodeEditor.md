# Frontend Component - CodeEditor

Full-featured in-browser code editor with syntax highlighting for config files (`.properties`, `.yml`, `.json`, `.toml`, `.py`).

## Features
- Line numbers, code folding, and auto-indentation.
- Save shortcut (Ctrl+S / Cmd+S) calling file update API.
