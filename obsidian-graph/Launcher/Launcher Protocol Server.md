# Launcher Protocol Server

**Source**: `src/launcher/protocol.ts`

The `Launcher Protocol Server` is a lightweight, local HTTP server hosted by the launcher process. It provides an authenticated IPC channel allowing the backend API to request supervisor actions (such as restarting the backend, checking launcher uptime, or initiating an auto-update).

## Endpoints
- `POST /api/supervisor/restart` (requires Bearer token generated by Supervisor)
- `POST /api/supervisor/shutdown`
- `GET /api/supervisor/status`
